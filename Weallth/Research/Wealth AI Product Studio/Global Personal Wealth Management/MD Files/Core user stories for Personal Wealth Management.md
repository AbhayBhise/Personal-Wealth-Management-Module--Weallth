# Core user stories for Personal Wealth Management

I can’t access my usual external sources right now, but I can still provide a strong set of **core user stories** for Personal Wealth Management based on standard wealth-management platform patterns.

## Core user stories (by persona)

### Client / Household

- As a client, I want to create my profile (residency, tax status, risk tolerance, time horizon) so that recommendations and projections are personalized.
- As a client, I want to link all my financial accounts (banking, brokerages, retirement, insurance, loans) so that I have a single consolidated net-worth view.
- As a client, I want to categorize assets and liabilities (including manual entry for private assets) so that my overall wealth picture is accurate.
- As a client, I want to see my net worth trend over time so that I can track progress.


### Advisor / Relationship manager

- As an advisor, I want to onboard a client digitally (KYC/AML, consent, disclosures) so that we can start planning quickly and compliantly.
- As an advisor, I want to view a household-level dashboard (accounts, goals, risks, opportunities) so that I can deliver advice efficiently.
- As an advisor, I want to track tasks and client requests so that service is consistent and auditable.


## Investment management (core)

- As a client, I want to see portfolio holdings, allocation, and performance across accounts so that I understand how my investments are doing.
- As a client, I want to compare my portfolio to a benchmark so that I can evaluate performance objectively.
- As a client, I want to set a target allocation and get drift alerts so that I know when rebalancing is needed.
- As a client, I want tax-aware insights (unrealized gains/losses, lots) so that I can make better sell decisions.
- As an advisor, I want to apply model portfolios and propose rebalancing trades so that I can manage many clients consistently.
- As an advisor, I want to generate client-ready reports (PDF, scheduled) so that reviews are professional and repeatable.


## Goals \& lifestyle planning

- As a client, I want to define goals (retirement, home, travel, education, philanthropy) with amounts and timelines so that my plan is goal-based.
- As a client, I want to see whether I’m on track for each goal so that I can adjust contributions or timelines.
- As a client, I want “what-if” scenarios (income change, major expense, market drop) so that I understand tradeoffs.


## Cash flow, budgeting, and debt

- As a client, I want to track income, spending, and subscriptions so that I understand my cash flow.
- As a client, I want a 30/90/180-day cash-flow forecast so that I can plan liquidity.
- As a client, I want an emergency fund recommendation based on expenses and risk so that I maintain resilience.
- As a client, I want a debt payoff plan (avalanche/snowball/refinance options) so that I can reduce interest and improve cash flow.


## Retirement planning

- As a client, I want retirement projections with multiple scenarios (age, returns, inflation) so that I can choose a realistic plan.
- As a client, I want withdrawal strategy guidance (account sequencing) so that I can reduce taxes and longevity risk.
- As an advisor, I want to document assumptions and plan versions so that advice is explainable and reviewable.


## Risk management \& insurance

- As a client, I want a risk assessment (life, disability, property, liability) so that I understand coverage gaps.
- As a client, I want recommended coverage ranges and affordability impact so that I can decide what to buy.
- As a client, I want to store policies and renewal reminders so that I don’t miss critical dates.
- As an advisor, I want to track insurance recommendations and client decisions so that compliance and suitability are recorded.


## Healthcare planning

- As a client, I want projected healthcare costs (inflation, retirement healthcare) so that my plan is realistic.
- As a client, I want long-term care scenarios so that I can plan for high-cost outcomes.


## Estate \& inheritance planning

- As a client, I want to maintain an estate inventory (assets, ownership, beneficiaries) so that my legacy plan is complete.
- As a client, I want to detect beneficiary mismatches (account vs will/trust intent) so that I can fix issues early.
- As a client, I want to store key documents (will, trusts, POA) securely and share access with trusted contacts so that they’re available when needed.
- As a beneficiary/heir (with permission), I want a guided inheritance workflow (what to do next, documents, timelines) so that administration is less stressful.


## Education, coaching, and engagement

- As a client, I want a personalized financial education path so that I can improve decision-making.
- As a client, I want nudges and coaching prompts (spend drift, savings shortfall, risk spikes) so that I stay on track.
- As an advisor, I want to assign learning modules and track completion so that coaching is measurable.


## Global, ESG, and philanthropy (if in scope)

- As a global client, I want multi-currency views and consolidated reporting so that I can manage cross-border wealth.
- As a client, I want ESG preferences and an ESG score overlay on my portfolio so that my investments match my values.
- As a client, I want to plan charitable giving (DAF, recurring gifts, tax impact) so that philanthropy is intentional and tax-efficient.


## Platform-level (must-have)

- As a user, I want secure login with MFA and device management so that my data stays protected.
- As a user, I want clear consent controls and audit history so that I know how my data is used.
- As a user, I want notifications configurable by channel (email/SMS/app) so that I’m not overwhelmed.
- As an admin, I want role-based access control (client/advisor/ops) so that data access is least-privilege.
