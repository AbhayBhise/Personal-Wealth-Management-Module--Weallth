## Process Comparison

### FinQy Car Par Loan Process

```
1. Enter car details → Instant AI valuation
2. Check eligibility → Up to 200% of car value
3. Upload documents → 100% digital
4. Verification → AI-powered
5. Instant soft approval → No manual follow-ups
6. Disbursement → Through lending partners
```


### CARS24 Loans24 Process[^5][^7]

```
1. Application → Digital form or callback request
2. Document submission → Minimal documentation
3. Verification → KYC, income, car verification
4. Approval → Quick, same-day possible
5. Disbursement → Direct to bank account
```


### RenewBuy RB Wheelz Process[^6]

```
1. Access digital platform → Integrated with insurance
2. Select loan product → New vehicle/balance transfer/top-up
3. Partner matching → 18 banks & NBFCs
4. Approval → Through lending partners
5. Disbursement → Partner-facilitated
```
