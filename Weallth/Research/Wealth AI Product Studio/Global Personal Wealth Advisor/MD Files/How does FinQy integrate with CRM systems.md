# How does FinQy integrate with CRM systems

Based on available research, here's what is known about **FinQy's CRM integration and lead management capabilities**:

## FinQy's Native Lead Management System

FinQy operates with a **built-in lead management system** rather than relying on third-party CRM integrations. This is core to their B2B2C distribution model.[^1]

### Core CRM-Like Capabilities

| Feature | Description |
| :-- | :-- |
| **Lead Capture** | Centralized system to capture leads from multiple sources |
| **Lead Tracking** | Login and track all leads in one place [^1] |
| **Dashboard Analytics** | Simple visual dashboard showing lead status and sales performance [^1] |
| **Intelligent Analytics** | Tools to monetize existing customer data for cross-sell/upsell [^1] |
| **Back-end Operations** | End-to-end support for managing partner operations [^1] |

## Integration Architecture

### API-First Approach

FinQy has adopted a **plug-and-play infrastructure** with a financial product API suite:[^2]

```
┌─────────────────────────────────────────────────────────────────┐
│                    FINQY PLATFORM                               │
│            (Plug-and-Play Infrastructure)                       │
├─────────────────────────────────────────────────────────────────┤
│  • Financial Product API Suite                                  │
│  • White-labeled Journeys                                       │
│  • Modular APIs                                                 │
│  • Embedded Finance Capabilities                                │
└─────────────────────────────────────────────────────────────────┘
              ↓                           ↓
┌─────────────────────────┐   ┌─────────────────────────┐
│   Partner Ecosystems    │   │   Financial Partners    │
│   (E-commerce, Portals) │   │   (Banks, NBFCs)        │
└─────────────────────────┘   └─────────────────────────┘
```

**Key Integration Features:**[^2]

- Modular APIs allowing partners to embed financial products
- White-labeled journeys for partner customization
- Contextual finance embedding at point of need
- Integration with e-commerce apps and employee portals

## Technology Stack Approach

### Embedded Finance Focus

FinQy's integration strategy focuses on **embedded finance** rather than traditional CRM integration:[^2]


| Approach | Description |
| :-- | :-- |
| **Contextual Finance** | Embedding credit/products at point of need |
| **White-labeled Journeys** | Partners can offer FinQy products under their brand |
| **Modular APIs** | Flexible integration with partner ecosystems |
| **Need-based Advisory** | Technology-backed financial nudges, not just product push |

### Partner Integration Options

| Integration Type | Use Case |
| :-- | :-- |
| **E-commerce Integration** | Embed lending at checkout |
| **Employee Portal Integration** | Offer financial products to employees |

| **NBFC Integration** | Digital lending workflows [^2] |

## Summary

FinQy's approach to CRM integration differs from traditional wealth management platforms:

1. **Self-contained ecosystem** — Partners use FinQy's native lead management rather than integrating external CRMs[^1]
2. **API-first for embedding** — Focus on embedding financial products into partner ecosystems (e-commerce, portals) rather than CRM sync[^2]
3. **Product distribution focus** — Optimized for distributing financial products (loans, cards, insurance) rather than comprehensive client relationship management
4. **Limited external CRM documentation** — No public information on Salesforce, Redtail, or other traditional CRM integrations

For advisors requiring deep CRM integration with platforms like Salesforce or Redtail, traditional wealth management platforms (Tamarac, RightCapital, eMoney) may be more suitable. FinQy is better suited for **financial product distribution partners** who can operate within FinQy's native lead management system.[^1][^2]
