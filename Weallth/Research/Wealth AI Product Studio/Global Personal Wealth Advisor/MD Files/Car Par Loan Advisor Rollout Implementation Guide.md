# Car Par Loan Advisor Rollout Implementation Guide

This comprehensive guide provides a complete roadmap for rolling out the Car Par Loan product to advisors, DSAs, and distribution partners across India.

***

## Executive Summary

Car Par Loan enables customers to borrow up to 200% of their car's current market value while retaining full ownership and use of the vehicle. This implementation guide covers the complete rollout process for onboarding, training, and enabling advisors to successfully distribute this product.[^1]

***

## Phase 1: Pre-Launch Preparation (Weeks 1-2)

### 1.1 Advisor Segmentation \& Targeting

| Advisor Segment | Profile | Priority | Target Volume |
| :-- | :-- | :-- | :-- |
| **Existing Auto Loan DSAs** | Already selling vehicle finance | High | 500+ advisors |
| **Credit Card Distributors** | G5 network partners | High | 200+ advisors |
| **Personal Loan DSAs** | Cross-sell opportunity | Medium | 300+ advisors |
| **Insurance Agents** | Vehicle insurance base | Medium | 400+ advisors |
| **New DSA Recruits** | Fresh onboarding | Low | 100+ advisors |

### 1.2 Infrastructure Setup

| Component | Requirement | Timeline |
| :-- | :-- | :-- |
| **Advisor Portal** | Car Par Loan module enabled | Week 1 |
| **Mobile App Update** | FINQY app with CPL features | Week 1 |
| **Training Materials** | Videos, guides, FAQs | Week 1-2 |
| **Commission Structure** | Defined payout tiers | Week 1 |
| **Lending Partner APIs** | Integration testing complete | Week 2 |
| **Support Helpline** | Dedicated CPL support team | Week 2 |

### 1.3 Product Knowledge Package

Advisors must understand these core features:[^2][^1]


| Feature | Details | Advisor Talking Point |
| :-- | :-- | :-- |
| **Loan Value** | Up to 200% of car's market value | "Get twice your car's value" |
| **Ownership** | Customer retains full ownership | "Keep driving your car" |
| **Tenure** | Up to 84 months | "Flexible 7-year repayment" |
| **Process** | 100% digital, instant soft approval | "No paperwork, instant decision" |
| **Usage** | No restrictions on fund usage | "Use for any need—education, medical, business" |
| **Transparency** | No hidden charges | "Clear terms, trusted lenders" |

## Phase 2: Advisor Onboarding (Weeks 2-4)

### 2.1 Registration Process

**Step-by-Step Advisor Onboarding:**


| Step | Action | Timeline | Owner |
| :-- | :-- | :-- | :-- |
| **1. Application** | Advisor submits interest via FINQY portal/app | Day 1 | Advisor |
| **2. Verification Call** | FINQY team explains process, fixes meeting | Day 1-2 | Sales Team |
| **3. Documentation** | KYC, agreement signing, bank details | Day 2-3 | Advisor |
| **4. Background Check** | Credit history, past experience verification | Day 3-4 | Operations |
| **5. Agreement Signing** | DSA agreement execution | Day 4-5 | Legal |
| **6. Code Assignment** | Unique DSA code for tracking | Day 5 | System |
| **7. Portal Access** | Login credentials, app activation | Day 5 | Tech Team |
| **8. Training Enrollment** | Assigned to training batch | Day 5-7 | Training Team |

### 2.2 Required Documentation

| Document | Purpose | Mandatory |
| :-- | :-- | :-- |
| **PAN Card** | Identity \& tax verification | Yes |
| **Aadhaar Card** | Address verification | Yes |
| **Cancelled Cheque** | Commission payout setup | Yes |
| **GST Certificate** | For registered businesses | If applicable |
| **Experience Proof** | Previous DSA/finance experience | Preferred |
| **Photos** | ID card creation | Yes |

### 2.3 Advisor Agreement Terms

| Clause | Details |
| :-- | :-- |
| **Territory** | Pan-India or region-specific |
| **Exclusivity** | Non-exclusive (can work with others) |
| **Commission** | As per published rate card |
| **Payout Terms** | Within 14 days of disbursal (24-hour option available) |
| **Compliance** | Must follow RBI/lender guidelines |
| **Termination** | 30-day notice either party |

## Phase 3: Training Program (Weeks 3-5)

### 3.1 Training Curriculum

**Module 1: Product Deep Dive (2 hours)**


| Topic | Content | Assessment |
| :-- | :-- | :-- |
| What is Car Par Loan | Product positioning, market need | Quiz |
| Key Features | 200% LTV, ownership retention, digital process | Quiz |
| Eligibility Criteria | Salaried, self-employed, business owners | Quiz |
| Loan Parameters | Tenure, amounts, interest rates | Quiz |
| Use Cases | Education, medical, business, emergencies | Role-play |

**Module 2: Customer Journey (3 hours)**


| Stage | Advisor Role | Tools Used |
| :-- | :-- | :-- |
| **Lead Generation** | Identify potential customers | CRM, referral tracking |
| **Initial Pitch** | Explain product benefits | Sales scripts, brochures |
| **Eligibility Check** | Run instant eligibility | FINQY app "Test My Loan" |
| **Documentation** | Collect required documents | Digital upload, checklist |
| **Application Submit** | Submit to lending partner | FINQY portal |
| **Follow-up** | Track status, assist customer | Dashboard, notifications |
| **Disbursal** | Confirm completion | Commission tracking |

**Module 3: Digital Tools Training (2 hours)**


| Tool | Function | Training Focus |
| :-- | :-- | :-- |
| **FINQY Mobile App** | End-to-end loan processing | Hands-on practice |
| **Instant Car Valuation** | Real-time market value check | Demo + practice |
| **Test My Loan** | Eligibility engine | Live simulation |
| **Q Report** | Credit assessment tool | Report interpretation |
| **CRM Dashboard** | Lead \& customer management | Navigation training |
| **Commission Tracker** | Payout monitoring | Real-time demo |

**Module 4: Objection Handling (2 hours)**


| Common Objection | Response Strategy |
| :-- | :-- |
| "Interest rate is high" | Compare with unsecured loans, highlight asset leverage |
| "I don't want to mortgage my car" | Explain hypothecation vs. mortgage, full usage retained |
| "What if I can't repay?" | Transparent terms, flexible tenure, no hidden charges |
| "Process seems complicated" | Demo 100% digital journey, instant approval |
| "Why not a personal loan?" | Higher amount (200% LTV), lower effective cost |
| "I need money urgently" | Instant soft approval, fast disbursal |

**Module 5: Compliance \& Ethics (1 hour)**


| Topic | Key Points |
| :-- | :-- |
| **RBI Guidelines** | Fair practices code, interest rate disclosure |
| **Customer Privacy** | Data protection, consent requirements |
| **Mis-selling Prevention** | Accurate information, no false promises |
| **Documentation Standards** | Authentic documents only |
| **Grievance Handling** | Escalation process, resolution timelines |

### 3.2 Training Delivery Methods

| Method | Format | Audience | Duration |
| :-- | :-- | :-- | :-- |
| **Classroom Training** | In-person at FINQY offices | Tier 1 city advisors | 2 days |
| **Virtual Training** | Zoom/Teams sessions | Tier 2-3 advisors | 3 sessions x 3 hrs |
| **Self-Paced E-Learning** | Video modules + quizzes | All advisors | 10 hours total |
| **Field Accompaniment** | Shadow senior DSA | New advisors | 2-3 customer visits |
| **Refresher Webinars** | Monthly product updates | All active advisors | 1 hour/month |

### 3.3 Certification Process

| Stage | Requirement | Pass Criteria |
| :-- | :-- | :-- |
| **Knowledge Test** | Online MCQ exam | 80% score |
| **Practical Demo** | Simulate customer interaction | Assessor approval |
| **Mock Application** | Complete dummy application | Error-free submission |
| **Certification** | Car Par Loan Certified Advisor | All 3 stages passed |
| **Recertification** | Quarterly refresher | Attendance + 70% quiz |
