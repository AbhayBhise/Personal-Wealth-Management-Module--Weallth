## Company Overview

**FinQy** (operated by E-REVBAY PRIVATE LIMITED) is an India-based B2B2C fintech platform founded in 2019 by Manish Aggarwal. The company secured \$2 million in funding in August 2024 and achieved revenue of **\$9.8 million in FY24**.[^1][^2][^3]


| Aspect | Details |
| :-- | :-- |
| **Founded** | 2019, Mumbai, India |
| **Business Model** | B2B2C platform for financial distribution |
| **Partners** | 100+ banks, NBFCs, and insurance companies |
| **Operations** | 30 offices across 24 cities, 2 countries (India, UAE, USA) |
| **Team Size** | 300+ employees |
| **FY24 Revenue** | \$9.8 million |

## Business Model

### B2B2C Platform Structure

```
┌─────────────────────────────────────────────────────────────────┐
│                    FINQY PLATFORM                               │
│         (Technology + Training + Support)                       │
└─────────────────────────────────────────────────────────────────┘
              ↑                                    ↓
┌─────────────────────────┐          ┌─────────────────────────┐
│   FINANCIAL PARTNERS    │          │    DISTRIBUTION         │
│   (B2B - Supply Side)   │          │    PARTNERS (B2B2C)     │
├─────────────────────────┤          ├─────────────────────────┤
│ • 100+ Banks            │          │ • DSAs                  │
│ • NBFCs                 │          │ • Financial Agents      │
│ • Insurance Companies   │          │ • Channel Partners      │
│ • Financial Institutions│          │ • Business Owners       │
└─────────────────────────┘          └─────────────────────────┘
                                              ↓
                                   ┌─────────────────────────┐
                                   │      END CUSTOMERS      │
                                   │      (Consumers)        │
                                   └─────────────────────────┘
```

**How It Works:**[^6][^2]

1. FinQy partners with 100+ financial institutions (banks, NBFCs, insurers)
2. Enables distribution partners (DSAs, agents, channel partners) to offer financial products
3. Partners use FinQy's technology platform to acquire customers and manage leads
4. FinQy provides training, technology tools, and operational support
5. Revenue generated through commission/payout structure

***

## Revenue Model

### Commission-Based Structure

| Revenue Stream | Description |
| :-- | :-- |
| **Payin from Financial Institutions** | Commission received from banks/NBFCs/insurers for each successful product sale |
| **Payout to Partners** | Commission shared with distribution partners |
| **Spread** | FinQy retains difference between payin and payout |

### Payout Structure for Partners[^5]

| Feature | Details |
| :-- | :-- |
| **Payout Cycle** | As short as 14 days |
| **Commission Slabs** | "Best slabs for payouts" (competitive rates) |
| **Bank Codes** | Pre-existing bank codes (no waiting required) |
| **Product Range** | Multiple products = multiple revenue streams |

### Revenue by Product Type (Indicative)[^9]

| Product | Payin Structure |
| :-- | :-- |
| Credit Cards | Per card issued + activation bonus |
| Insurance | Percentage of premium |
| Loans | Percentage of loan disbursed |
| Investments | Trail commission on AUM |
