# Details on upcoming Q personal finance manager app

Based on my research, here's what is known about **FinQy's upcoming Q App personal finance manager**:

## Q App Overview

The Q App is FinQy's planned **consumer-facing personal finance manager application** designed to complement their existing B2B2C distribution platform.[^1][^2]


| Aspect | Details |
| :-- | :-- |
| **Product Name** | Q App |
| **Type** | Personal Finance Manager (PFM) |
| **Target Users** | Individual consumers (B2C) |
| **Status** | In development / Planned launch |
| **Funding Allocation** | Part of \$2M funding round (August 2024) |

## Strategic Purpose

### Why FinQy is Building Q App

| Objective | Description |
| :-- | :-- |
| **B2C Market Entry** | Expand beyond B2B2C distribution to direct consumer engagement [^1] |
| **Data Insights** | Gather consumer financial behavior data to enhance AI recommendations |
| **Product Cross-sell** | Create channel to offer credit cards, loans, insurance directly to consumers |
| **Ecosystem Completion** | Connect consumers with FinQy's 100+ financial institution partners |
| **Unicorn Ambition** | Part of strategy to achieve unicorn status within 3-5 years [^1] |

While specific Q App features haven't been publicly detailed, based on FinQy's existing technology and standard PFM capabilities, the app likely includes:

### Core PFM Features

| Feature Category | Expected Capabilities |
| :-- | :-- |

| **Expense Tracking** | Categorize and monitor spending patterns |
| **Budgeting Tools** | Set budgets by category, track against targets |
| **Financial Insights** | AI-powered analysis of spending and saving habits |

Based on FinQy's existing proprietary tools, Q App may integrate:
